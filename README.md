# 🍉 Fruit Cut Game

A fun and interactive 2D Fruit Cut Game built using HTML, CSS, and JavaScript. Slice falling fruits to earn points while avoiding bombs. The game features smooth animations, collision detection, score tracking, and an engaging user experience.

## 🚀 Features
- Slice falling fruits
- Avoid bombs
- Real-time score tracking
- Smooth animations
- Responsive gameplay
- Simple and attractive UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ▶️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/daliakshayabande-afk/Fruitcut.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## 📂 Project Structure
- `index.html` – Main webpage
- `style.css` – Styling
- `game.js` – Game logic
- `physics.js` – Physics calculations
- `entities.js` – Game objects
- `audio.js` – Sound effects
- `backgrounds.js` – Background handling
- `ui.js` – User interface

## 🎮 Gameplay
Slice as many fruits as possible to score points. Avoid bombs, as hitting one ends the game.
